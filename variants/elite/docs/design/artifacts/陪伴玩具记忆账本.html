关键路径：孩子说完到玩具开口

  1. ASR 转文字 · 产品侧，不计
  2. 检索 5 条相关记忆 · 本地 6–30 ms，含查询嵌入 3.8 ms
  3. 拼上下文 ≈ 87 token · 本地 <1 ms
  4. 对话 LLM 生成回复 · 产品侧；记忆上下文若走 deepseek-flash 约 ¥0.00009/轮
  5. TTS 播放 · 产品侧

记忆层在关键路径上只占毫秒级，回复延迟由 ASR、对话 LLM、TTS 决定。

旁路：把这句话变成记忆

  1. Txn A 源事件 + 见证锚点落库 · 本地约 5 ms，此后原话已不可丢
  2. 抽取 deepseek-flash，compact 契约（可选，库默认 full）只输出 text / type / speaker / 日期 / 修订引用 / entities · 约 2.3 s
  3. 本地推导 情绪、主题、实体、谓词等 7 轴 · 毫秒级
  4. Txn B 原子 + 边 + 向量索引落库 · 本地约 5 ms
  5. 可检索 说完约 2.4 s 后；若孩子 2.4 s 内又说了下一句，这一段由对话 LLM 自己的上下文窗口覆盖
记忆层在这个场景里做的三件事：修订不删除（「最喜欢奥特曼」→ 一个月后「现在最喜欢恐龙」，新原子经 supersession 边替代旧原子，旧的保留为历史，检索默认只回当前有效的）；情绪轴（每条原子带 sentiment，状态卡片能给出最近几天的情绪走向，供对话 LLM 调语气）；可回溯（每条记忆指向原话的见证锚点，家长端能看到「玩具为什么这么记」）。

A 的单句费用是 B 的三倍多：每次请求都要重读系统提示词（缓存命中 1,280 token），并输出完整信封（456 个输出 token 里只有约 80 个是记忆本身）。产品上可以混合：情绪强烈或明确的「记住这个」用 A，其余用 B。

存储增长 实测折算

r3 整库 54.6 MB / 8,439 条原子，即每条原子连同源事件、锚点、FTS 与 384 维向量约 6.5 KB（实测）。A 策略每台每月约 9 MB，B 约 15 MB；一年 105–180 MB/台，单机 SQLite 可承载，万级用户需按用户分库或换 Milvus 索引提供者。
