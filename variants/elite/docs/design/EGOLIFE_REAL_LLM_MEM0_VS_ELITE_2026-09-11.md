# EgoLife 真实 LLM 同口径对照：mem0 vs HMS Elite（2026-09-11）

控制变量：同一题库（204 题）、同一窗口切分与批次（290 批 / 4,851 窗口）、同一流式时间线、同一抽取模型与参数（deepseek-flash，temperature 与 max_tokens 相同）、同一本地嵌入器（fastembed bge-small 384 维）、同一阅读器提示词与参数（四选一，temperature 0，max_tokens 8）、同一 top-k=20 与阈值、并发 1。不同点只在引擎本身：mem0 用其官方 Memory（milvus-lite 混合检索，add 无时间戳参数，v2 写入只 ADD）；Elite 用 sqlite 索引与 compact 抽取契约、`reference_date` 有效期判定。
所有数字由 questions_*.jsonl / calls.jsonl / retain_*.jsonl 重算；费用同时给 API 实际账单（USD，按请求时刻档位）与人民币同口径重算（全部按空闲 / 全部按高峰）。

## 6. 口径说明

- Elite r3 = full 抽取契约（JSON，17 字段）、批次 25；elite_compact_v2_full204 = compact 契约修订版（JSON，9 键 + 判定守卫）；elite_lines_full204 = lines 契约（文本行，观察一行一条，EP / 判定段仅在出现时写）。compact 初版（53.9%，根因：模型按位置把观察与候选配对判 NONE）与批次 12 实验（54.9%）已从表中移除，见 results/real/。三轮 Elite 之间除输出契约外配置相同；库默认仍为 full。
- mem0 的 add 没有时间戳参数；各臂的记忆行上下文都不带时间戳。r3 的 773/886 请求落在高峰档，其余各轮全部在空闲档；跨臂比较费用请看人民币同口径两行。
